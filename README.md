# Адвент-календар

Статичний календар на HTML, CSS і JavaScript. Laravel та збірка не потрібні.

## Локальний запуск

```sh
python3 -m http.server 8765
```

Відкрийте [http://localhost:8765/](http://localhost:8765/).

## Налаштування

- Завдання та дата для тестування лежать у `js/data.js`.
- `previewDate` приймає дату `YYYY-MM-DD`; **перед публікацією встановіть `null`**.
- Дні відкриваються о 00:00 за Києвом; відкритий стан зберігається у браузері.
- `task.text` підтримує довірену HTML-розмітку, наприклад `<a href="https://example.com">Назва</a>`.
- На екранах до 600 px календар має дві колонки.

Це клієнтський календар: код і тексти завдань можна переглянути у браузері до дати відкриття. Для приховування майбутніх завдань знадобиться серверна видача контенту.
